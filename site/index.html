Eido

An interface that changes, inside limits you can see.

Eido is the design language of ML Weft. Weft studies models that change themselves within bounds you can check. Eido uses the same rule on the screen. The page can change itself in response to you, and only within bounds you can see, check and undo.

This page is one field, not a row of boxes. Every line of work in the repository lives in the field below. Pick a place and it runs here. Three threads run through all of it at once: the style point, how restlessly you read, and the tension of a small test model. Move one thread and the whole field answers.

Style. A point you can drag

A style here is not a fixed theme. It is one point inside a triangle. Each corner is a preset. The point gives the weight of each preset, and the weights always add to one. Drag the point and this whole page changes with it: corner roundness, spacing, colour and contrast. Hue is averaged around the colour circle, so two reds never blend into cyan.

Reading. Text that answers how it is read

This page watches how you read it. A restlessness score rises when you skim and falls when you read. The score never leaves the page. Skim the text below and it starts to ripple. Read slowly and it settles. Skim hard enough and the text rewrites itself shorter, one step at a time. A panel at the bottom right shows the score and can switch all of it off.

Most pages treat every visitor the same. A careful reader and a hurried one get the same words in the same order. Eido treats how someone reads as a signal the page can answer. The answer stays inside limits the reader can see. Nothing moves under the setting that asks for reduced motion. The element you have focused never moves. Text stays text for assistive technology.

Condensing prose is the second answer to the same signal. Each time the score crosses a step, the passages still on screen are rewritten shorter. First concise, then terse, then caveman, then one line per section. The shorter versions are written ahead of time by an author. The page never calls a model, so what you read is what an author approved.

Field. The GPU rebuild, in miniature

One line of work drops the document entirely. A single shader draws every cell, letter and slider per pixel on the GPU. The full version needs WebGPU and lives in an open pull request. What runs here is a small canvas version of the same idea, driven by the same three threads. It makes no network requests and stores no keys.

The full rebuild is not part of this site yet. Its page looks up your network address from a third party when it loads, and its bridge code can hold service keys in the browser. Review asked for both to change before it merges. The link below opens its pull request, and it arms only after you ask.

Identifiability. Can two measurements tell four cases apart?

Four cases can look alike through two measurements. Each case below is a cloud of points. The band around each cloud shows how far a reading can stray. Widen the bands and the cases merge. When bands overlap, no rule based on these two measurements can tell those cases apart. The full explorer uses the project data and a stricter distance rule.

Harmonic. The system as sound

One line of work turns the system's state into chords. Press play to hear it. The style hue picks the root note. Tension stretches the interval. Restlessness sets the loudness and pace of change.

Sound starts only when you press play. It stops when you press stop or leave this place. The tones here are made in your browser. The recorded pieces on the harmonic pages are under CC BY-NC 4.0. You can share them with credit. You cannot use them commercially.

The three threads

Nothing on this page runs alone. The style point sets how everything looks. Your reading sets how calm everything is. The toy model sets how much strain everything shows. Each thread has a number you can read and a way to take control back.

Tension. 0.00 from the toy model. Take it back in the Explainer place with Reset, or in the Field place with its slider.

Two principles have no place of their own because they run elsewhere. Compact verified state and surfaces that show strain live in Weft's telemetry field, built on these modules. The philosophy page says plainly what is built here, what lives in Weft, and what is still design.
