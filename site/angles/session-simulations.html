What it can do

  • E08 to E10: propose changes to a small matrix and see each one accepted or rejected by a distance gate.
  • E11: compare a structured generator with a scrambled copy and with direct search, at four sizes.
  • E12: graft a skill from one model onto another and compare a gated graft with two ungated ones.
  • E13: scrub through a three-step hand-off between cells and see which of four gating rules keeps all three skills.
  • Five paths: four small studies on one stage, each with a slider that changes meaning per study.

Concepts

E08–E10

Change inside a radius

Rows 0 and 1 of an 8×8 matrix are frozen. A change to the rest is kept only if the whole matrix stays within radius R of its start.

E11

Unfolding scales, search does not

The recorded scores for the structured generator rise with size (+33.48 at 64² to +39.51 at 512²). The scrambled and direct arms fall to about zero.

E12

Graft into the unused directions

A change is projected so it has no effect along the directions the host already uses: ΔW(I − QQᵀ). The gated arm keeps its own skill and gains the new one. The ungated arms lose both.

E13

Skills that survive a second hand-off

Each transferred skill is tagged with the subspace it occupies, so a later graft does not overwrite an earlier one. Only the tagged arm ends with all three skills.

Five paths

Telling four cases apart

A mixture model with four hypothetical cases. The panels show how far apart two measurements can push them compared with a noise floor of 1/60, and how three yes-or-no tests give each case its own three-bit code.

Techniques

  • The main suite uses Canvas2D with one shared animation loop that draws only the open tab.
  • E13 and the five-path explorer use inline SVG, updated by setting attributes.
  • A scrub slider interpolates between three stored snapshots of the cascade.
  • Colours use the CSS light-dark() function, and the canvas reads them back each frame.
  • Deep links: ?sim=morphogenesis and ?sim=plasmid open a tab directly.

Style

An instrument panel. A narrow centred column, pill tabs, metric cards with tabular numbers and one rounded stage. Blue is the working colour, green means held, amber means watch, red means failed.
