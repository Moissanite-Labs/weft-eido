Design modules

A theme is usually a switch: light or dark. Here a style is a point you can drag, a layout gives each visual channel one quantity to carry, and letters come from a table of numbers that two different renderers read the same way.

Each module has its own page with options and source: aesthetic mixer, simplex pad, cell layout, glyph font.

What it can do

  • Blend any number of style presets with weights, and get one style back: rounding, density, hue and contrast.
  • Give the reader a triangle to drag instead of three sliders. It works with a pointer or the arrow keys, and it tells screen readers its value.
  • Lay out a set of cells so the area of each one is its value, in a region of any shape.
  • Draw the same letters on the GPU and on a canvas from one 5×7 font table.

Concepts

D1

A style is a blend

A style is four numbers. Any style is a weighted mix of a few presets, and the weights always add up to one.

D1

Hue is averaged on a circle

Hue wraps around. Average two reds at 0.95 and 0.05 the plain way and you get cyan at 0.50. The mixer turns each hue into an angle and averages the angles, so two reds stay red.

D1

The point is the weights

Three sliders cannot show that three weights must add up to one. A triangle can. Every point inside it stands for exactly one set of three weights.

D2

One channel, one quantity

Area means value. Position means rank. Threads join the cells in a group. Because each channel carries one thing, the legend can say what it is.

D2

Text from a table

Each glyph is a 5×7 grid of bits stored in two 32-bit words. An earlier design packed it into one word, which cannot hold 35 bits.

Techniques

  • Barycentric weights, normalised so they sum to one.
  • Circular mean for hue: atan2(Σ w·sin θ, Σ w·cos θ).
  • Golden-angle packing (137.508°) stretched to the region, with the scale fitted by bisection.
  • A minimum spanning tree (Prim) for the threads inside each group.
  • Layout runs on the CPU in CSS pixels, so the renderer gets exact rectangles.
  • Plain ES modules with tests, no build step.
