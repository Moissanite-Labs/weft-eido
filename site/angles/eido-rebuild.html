Eido rebuild

This angle asks how far the idea goes if you give up HTML layout altogether. The page is one canvas. Cards are distance functions, text is the 5×7 bit font, and the background is a ray-marched fractal. It is an experiment, and several parts its manifesto describes are not wired up yet.

Try it

weft-eido/index.htmlOpen full page

Loading this page sends a request to ipwho.is, a third-party service that looks up your approximate location from your IP address. Nothing else is sent unless you enter an API key.

It needs a browser with WebGPU. Keys: space toggles self-adjustment, 1 to 3 pick one of the three styles. The K key asks for an API key and stores it in your browser. Leave that alone unless you mean to use it.

What it can do

  • Draw a 4×2 grid of rounded cards, their labels and six sliders in one full-screen pass.
  • Blend three named styles with the same weights-on-a-triangle maths as the design modules.
  • Score how the visitor is moving (speed, reversals, repeated clicks, dwell) and feed that into the picture.
  • Run a small graph-rewriting machine on each scroll event.

Concepts

What is built, and what is still only described.

Layout as per-pixel maths

Each card is a signed distance function: a formula that says how far a pixel is from the card's edge. Edges stay sharp at any zoom and need no images.

Text in the shader

Fourteen eight-character labels are packed into a buffer. The shader looks up each glyph's bits and lights the pixels.

A reflex layer

A five-second window of pointer and scroll activity gives four scores. They are hand-set heuristics. The code calls them calibrated, but nothing calibrates them.

A combinator machine

A small machine for interaction combinators, a model of computation by rewriting a graph. Two rewrite rules exist so far, and each scroll event starts it over.

Not wired yet

The cellular automaton and edge kernels in the manifesto are not in the code. Remote answers are parsed and mostly unused. The team numbers on screen are fixed values, not read from the data file.

Techniques

  • One full-screen triangle per frame, with a 96-byte uniform buffer and a storage buffer for labels.
  • A 32-step ray march of a folded, rotated fractal behind the cards.
  • Smooth-minimum blending so neighbouring cards appear to bridge.
  • A Canvas2D fallback that draws plain rounded boxes when WebGPU is missing.
  • A Python gate that fails the build if the page contains layout HTML or more than one canvas.

Style

Near-black with thin glowing strokes, film grain and three style poles: a hard teal one, an airy violet one and a calm sage one. There are no fonts at all, since every letter is a 5×7 bitmap.
