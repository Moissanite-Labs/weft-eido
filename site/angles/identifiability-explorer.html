Identifiability explorer

This is the first entry in a collection of archived visualizations. It is the one angle here where every number on screen is worked out from a formula as you drag. The mathematics describes synthetic cases only. The folder's README says so, and says it makes no clinical claim.

The page loads fonts from Google Fonts and follows this site's light or dark theme.

What it can do

  • Plot four response curves from one formula with different settings.
  • Choose a low and a high measurement point with sliders, or jump to four presets.
  • Compare two ways of measuring separation against a noise floor of 1/60.
  • Add a cross-talk term and see it make one case imitate another, then see a third measurement expose it.

Concepts

The model

Each case is a curve q(p) = (r·p + c·(1−p)) / (r·p + (1−p)) over a mixing proportion p. Four pairs of r and c give four cases.

Slope test

Compare how much each curve rises from the low point to the high point. At the default preset this margin is 0.01805, just over the floor of 0.01667.

Box test

Compare the curves at both points and take the larger gap. This is the Chebyshev, or maximum, distance. The same two measurements give 0.03393, about 1.88 times the slope margin.

The pivot

At p = 0.20 the pure cases all read 0.80. A reading away from 0.80 there means cross-talk is present, which the two-point test alone cannot see.

Techniques

  • Each curve is an SVG path built from 121 sample points.
  • There is no animation loop. The chart is redrawn once per slider movement.
  • The numbers turn green or red by comparing them with 1/60.
  • The page is built for embedding: transparent background, and it accepts a theme message from the host page.

Style

The same generated widget look as the original research graphics: segmented pills, summary cards, custom slider thumbs. Colour is spent on meaning, with green for clears the floor and red for misses it.
