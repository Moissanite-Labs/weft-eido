Research explainer

The research graphics that inspired this were generated one page at a time. This module is the clean, reusable version: helpers you can test, and one mount function that wires buttons, sliders, numbers and a canvas to a single state. The toy model here is an illustration, not evidence for any experiment.

What it can do

  • Wire a whole explainer from markup: buttons with data-action, sliders with data-range, numbers with data-kpi, and a canvas.
  • Step a small 8×8 model where a move is accepted only if it stays within a set distance of the start.
  • Keep a frozen core that no move can touch, and show that its drift is zero.
  • Repeat exactly: the same seed gives the same run.

Concepts

A bound you can drag

Each step proposes a change. It is accepted only if the matrix stays within distance R of where it started. Lower R and more moves are rejected.

A frozen core

The top two rows never change, by construction. The metric reports their drift so the reader can see it stay at zero.

Numbers and picture agree

The readouts and the canvas are both drawn from one state object, so they cannot disagree.

Labelled as a toy

The module marks its model as illustrative. The three lenses change how the right-hand field is drawn. They are not three different models.

Techniques

  • A seeded random number generator, so runs repeat.
  • Pure helpers for distance, drift, formatting and clamping, each with tests.
  • A canvas sized to its box times the device pixel ratio, redrawn on resize.
  • Animation is skipped when the system asks for reduced motion.

Style

The site's palette on a canvas: teal cells for positive values, sand for negative, a gold outline around the frozen rows. The canvas colours are fixed, so it stays dark in the light theme.

  • #090d0f ground
