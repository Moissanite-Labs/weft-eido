What it can do

  • Statistical cell: step an 8×8 matrix by making two candidate copies, a cautious one and a bold one, and keeping the better one if it passes the gate.
  • Statistical cell: move the pointer over the right-hand field and a soft shape chases it, driven by the matrix.
  • Morphogenesis: compare three ways of producing a large matrix, and change its size from 64² to 512².

Concepts

The safety gate

A candidate is accepted only if its distance from the starting matrix is at most R. The distance is the Frobenius norm: the square root of the sum of squared differences.

Two candidates per step

The page calls this A/B mitosis. Copy A takes a small step. Copy B takes a larger, noisier one. Both are gated and scored, and the winner is kept only if it beats the current score.

Score with a novelty term

The score rewards matching a target and adds a bonus for output that differs from a fading memory of recent output.

A small program that unfolds

The morphogenesis page claims a 492-byte graph program expands into a matrix of up to 512×512 numbers, and compares it with a scrambled copy and with evolving the matrix directly.

What is drawn, not computed

The results table on the morphogenesis page is a fixed lookup. The page illustrates a reported result. It does not run the experiment.

Techniques

  • Canvas2D with one animation loop, scaled for the device pixel ratio.
  • Canvas colours are read from CSS variables every frame, so the drawing follows the theme.
  • The data is procedural, made from seeded sine hashes.
  • A shared generated stylesheet of about 1,400 lines supplies the buttons, cards and sliders.
  • The page accepts a theme message from a host page, which this site uses.

Style

Clean and quiet in the manner of Google's Material widgets: pill buttons, three metric cards, one rounded stage, a deck of sliders. Blue for positive values, amber for negative, a dashed green box around the frozen rows.
