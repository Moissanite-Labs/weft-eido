Aesthetic mixer

Blend a few style presets into one style. Rounding, density and contrast average linearly. Hue averages on the circle.

Components / Aesthetic mixer

What it is

A style is four numbers: rounding, density, hue and contrast. The mixer takes a few reference presets and a weight for each, and returns the blend.

Hue needs care because it wraps around. Crimson at 0.95 and scarlet at 0.05 are both red. A plain average gives 0.50, which is cyan. The mixer averages the angles on a circle instead, so the midpoint stays red.

Principle: D1 · Style as a point in a continuous space.

API

mixAestheticPresets(presets, weights)

ArgumentDefaultMeaning
presetsrequiredObject of name → { rounding, density, hue, contrast }. hue_shift is accepted as an alias for hue. Missing fields count as 0.
weightsnoneObject of name → number. Negative values count as 0 and the rest are normalised to sum to 1. If every weight is 0, the first preset gets all of it.
returns{ rounding, density, hue, contrast }. Hue is in [0, 1). With no presets you get a fixed default style.

class AestheticMixer

A small stateful wrapper around three built-in slices. setSliceWeight(id, weight) changes one weight. calculateUnifiedAestheticVector() returns the blend.
