Simplex pad

A triangle you drag. The point is the blend: its distances to the three corners are the three weights.

Components / Simplex pad

What it is

Three sliders that must sum to one fight each other. A triangle does not. Every point inside it has exactly one set of three weights that add up to one, so dragging the point is moving through the blend.

The pad works with a pointer, a finger or the arrow keys. It exposes its value as a slider to screen readers. Points dragged outside the triangle snap to its edge.

Principle: D1 · Style as a point in a continuous space.

Try it

Keyboard: focus the triangle, then press the arrow keys. Each press moves the point by 2% of the triangle height.

API

mountSimplexPad(container, options)

OptionDefaultMeaning
labelsrequiredThree vertex names, top, bottom-left, bottom-right.
weights[1, 0, 0]Starting weights. They are normalised onto the simplex.
hues[]Optional hues in [0, 1) used to colour the three vertices.
onChangenoneCalled with the normalised weights [wA, wB, wC] on every change.
returns{ set(weights, emit = true), get() }.

Pure functions

All take points as [x, y].

FunctionMeaning
barycentric(p, a, b, c)Barycentric coordinates of p in triangle abc. Throws on a degenerate triangle.
pointFromWeights(w, a, b, c)The point for weights w.
projectToSimplex(w)Clamps negatives to 0 and renormalises to sum 1.
weightsAt(p, a, b, c)Weights for a pointer position. Outside the triangle they snap to the edge.

CSS classes the pad uses

.simplex-pad, .simplex-guide, .simplex-edge, .simplex-vertex, .simplex-label, .simplex-spoke, .simplex-knob. The module ships no stylesheet, so style these yourself.
