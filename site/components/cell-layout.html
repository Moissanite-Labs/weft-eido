Cell layout

Give each visual channel one job. Here, a cell's area is its value, and nothing else.

Components / Cell layout

What it is

Cell layout places labelled squares in a region. A cell's side is the scale times the square root of its value, so area ratios equal value ratios at every size. Position comes from rank: the biggest cells sit near the middle, and the rest spiral out at the golden angle (137.5°). The spiral is stretched to the region's shape, and the scale is fitted so everything fits.

Cells in the same group are joined by the shortest set of threads that connects them (a minimum spanning tree). hitTest tells you which cell is under a point.

Principle: D2 · Analytical geometry and reading cadence.

API

layoutCells(items, region, options)

OptionDefaultMeaning
itemsrequiredArray of { weight, labelLength }. Weight is the value. Label length is in characters.
regionrequired{ width, height } in CSS pixels.
options.padding16Clear margin inside the region.
options.gap12Minimum clearance between cells, labels included.
options.labelGap6Space between a cell and its label.
options.labelHeight10Label cap height.
options.charWidth8.4Label advance per character.
options.maxSideFraction0.3Largest cell side as a share of the region's shorter side.
options.iterations28Bisection steps when fitting the scale.
returns{ scale, fits, cells, bounds, region, options }. Each cell has centre x, y, side, half, labelW and footprint fp, in region coordinates, in input order.
