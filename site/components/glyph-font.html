Glyph font

A tiny font stored as numbers. A shader and a canvas read the same table and draw the same letters.

Components / Glyph font

What it is

Each glyph is a 5-column, 7-row grid, which is 35 bits. That does not fit in one 32-bit word, so each glyph uses two. The CPU can check the table, and the GPU can upload it as a buffer. A Canvas2D fallback reads the same words, so both draw identical letters.

The font covers A–Z, 0–9 and a few symbols. Lowercase draws as uppercase. Anything else draws as ?.

Principle: D2 · Analytical geometry and reading cadence.

API

ExportValueMeaning
GLYPH_COLS, GLYPH_ROWS5, 7Glyph grid size.
GLYPH_ADVANCE6Horizontal advance in glyph pixels (5 columns plus 1 of spacing).
CHARSETString of every character the font can draw.
packGlyph(rows)Packs 7 strings of 5 characters (# or .) into [lo, hi]. Bit b = row·5 + col; bits 0–19 go in lo, 20–34 in hi.
glyphBit(words, col, row)Reads one pixel back. Out-of-range positions return 0.
fontCode(ch)ASCII code the font draws for a character. Unknown characters give 63 (?).
encodeFontTable()Uint32Array(256), two words per ASCII code, ready for a storage buffer.
packLabel(text, maxChars = 16)Packs up to 16 characters, four per word. Returns { words, length }.
