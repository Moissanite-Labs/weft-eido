Components

Six small modules

Each one is a plain ES module with no dependencies and no build step. Each page has a live demo, the files to copy, a snippet that works when pasted, and the full source.

D1src/aesthetic-mixer.js

Aesthetic mixer

Blends style presets with barycentric weights. Hue averages on the circle.
D1src/simplex-pad.js

Simplex pad

A triangle control. The point you drag is the weight vector.
D2src/cell-layout.js

Cell layout

Cell area follows value. Golden-angle packing fitted to any region.
D2src/glyph-font.js

Glyph font

A 5×7 bitmask font, two 32-bit words per glyph, the same table for GPU and Canvas.
D6src/reading-weave.js

Reading weave

Text ripples when you skim. Reading calms it.
D6src/condense.js

Condensing prose

An article condenses, level by level, as you skim.
