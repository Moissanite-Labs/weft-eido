# Security policy

Please report vulnerabilities privately, not as public issues. Use GitHub's
[private vulnerability reporting](https://github.com/Moissanite-Labs/weft-eido/security/advisories/new) or email
**security@w3ft.org**. The full policy for all ML Weft repositories is in
[Moissanite-Labs/weft](https://github.com/Moissanite-Labs/weft/blob/main/SECURITY.md).
