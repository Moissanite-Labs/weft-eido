# Causal Harmonic Computing: Syntactic Weft to Symphonic Wavelengths

Causal Harmonic Computing in one line: compute by resonance, not by arithmetic.
Coupled oscillators lock into rational frequency ratios, literal chords on a
Just Intonation lattice, and the state of the machine can be heard as consonance
or dissonance. This folder holds the material for that idea as it arrived on
2026-11-15: the untouched uploads in `originals/`, the source paper in
`paper.md`, and the site subpages under `site/causal-harmonic/` that show each
part working.

## What is here

- `originals/` holds every file exactly as uploaded. Nothing in it is edited,
  merged, or re-skinned. Duplicates are kept on purpose so the archive is
  complete. The file names are the uploaded names.
- `paper.md` is the source paper, "Causal Algorithmic Symphonic Synthesis".
  It turns the Syntactic Weft code (ahraz.md, almalga.md, emergent.md,
  ethos.md) into a full written spec: each mechanism as a chord, three causal
  strata, symphonic wavelengths, and a bare-metal audit with a verified kernel
  for the M1 Max.
- `site/causal-harmonic/` holds the Pages subpages. They do not frame these
  files. They rebuild their ideas on the site's own runtime and compute every
  figure live: the six mechanisms as chords, sensory roughness, Kuramoto
  locking, Arnold tongues and wavelengths in air (`index.html`); a cellular
  automaton, the Halvorsen attractor, a tensioned plate with sand and the
  orthogonal provenance projector (`weft.html`). The Paper page shows the
  paper. The Soundtrack page plays "The Paracausal Loom" with lyrics that
  follow the song. The Originals page links every upload, untouched.
- Where an original showed a fixed series (the watermark decay, the Kuramoto
  bars, three of the plate overtones), the site computes it instead from the
  stated model, so its numbers can differ from the originals'. The plate model
  does reproduce the originals' anchors: 38.56 Hz at T = 20 and 75.13 Hz at
  T = 84.5.

- Syntactic Weft `__3` is the latest content. It adds the Somatic Kinetic

- Syntactic Weft `__1` and the unnumbered file have identical text. `__1`
  only fixes the copy button inside an iframe.

  Python kernel inside. Keep it as a skin, not as the latest content.

## Limits

- The pages contain generated inline CSS and JavaScript. The Weft and
  Explorer pages load Google Fonts from the network.
- The numbers in the paper and the pages are the authors' claims, not results
  this repository has verified. The point-charge counts and the gravity
  crossover in the paper come from deep-research threads whose synthesis
  check is still open. Do not cite them as project results.
- The paper's Works Cited contains an `unknown_url` entry. It is left as-is
  here. No URL was invented for it.
- The 5 defects in the paper's audit (vm_statistics64 layout, int.from_buffer,
  shared-memory clobber, LoRA watermark erosion, x86 mnemonics in an ARM64
  routine) are claims about earlier manuscripts, not findings of this repo.
- The soundtrack lyrics are a transcription from the video's subtitle track.
